一键安装 / 更新

如果点击后浏览器只是把代码显示成文本，说明 Tampermonkey 没有接管这个链接。请改用下面的「手动安装方式」。

手动安装方式（最可靠）

  1. 点击下面的按钮，把脚本全文复制到剪贴板。
  2. 打开 Tampermonkey 图标 →「管理面板」。
  3. 在左侧/顶部找到「AI 回答发送到 ZenMark …」，直接删除旧的那条（避免两份副本冲突）。
  4. 点「+ 添加新脚本」，全选编辑器内容（Ctrl/Cmd + A），粘贴覆盖，然后 Ctrl/Cmd + S 保存。
  5. 回到 AI Mode 页面刷新一次，控制台执行 __zenmarkInstances 验证。

验证是否装上

  1. Tampermonkey 图标 → 该脚本，右上角「版本」应显示 1.4.1；
  2. 页面控制台执行 __zenmarkInstances，应返回一个包含 "version": "1.4.1" 的数组；
  3. 再执行 __zenmarkAIDiag() 查看 AI Mode 的回答识别情况。
