# My Scripts

这是一个用于收集和管理我所有的个人脚本的集中仓库。

## 目录结构

*   **`userscripts/`**: 存放所有的浏览器油猴脚本 (Tampermonkey/Greasemonkey 等)。
*   **`notebooks/`**: 存放所有的 Python Jupyter Notebooks (数据分析、实验性代码、数据处理等)。
*   **`automation/`**: 存放所有的本地自动化脚本 (Python/Node.js 等编写的系统自动化、爬虫、定时任务等)。
*   **`shell/`**: 存放所有的 Shell 脚本 (Bash/Zsh 等常用的终端快捷脚本、环境配置等)。
